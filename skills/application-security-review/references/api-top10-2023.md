# OWASP API Security Top 10:2023

Activated when `framework-selection.md` detects an API surface. It **supplements,
does not replace**, the web Top 10 for API-backed apps — several of these risks
are invisible to a generic review because the code looks syntactically clean; the
flaw is a missing authorization or limit.

| Code | Title | Code-review cue | Maps to ASVS |
|---|---|---|---|
| **API1:2023** | Broken Object Level Authorization | object fetched by id (`findUnique({ where:{ id } })`) with no check that the caller owns/may access it | V8 Authorization |
| **API2:2023** | Broken Authentication | weak/missing token verification, `alg:none` accepted, no lockout, guessable reset tokens | V6 Authentication; V9 Self-contained Tokens |
| **API3:2023** | Broken Object Property Level Authorization | mass assignment (whole request body bound to model); over-broad response exposing fields the caller shouldn't see | V8; V14 Data Protection |
| **API4:2023** | Unrestricted Resource Consumption | no rate limit / pagination cap / payload size limit / query cost limit; unbounded loops over user input | V2 Validation; V13 Configuration |
| **API5:2023** | Broken Function Level Authorization | admin/privileged routes protected only by obscurity or client-side checks; role not enforced server-side | V8 Authorization |
| **API6:2023** | Unrestricted Access to Sensitive Business Flows | a business flow (purchase, signup, reservation) exploitable by automation without anti-abuse controls | V2 (business logic) |
| **API7:2023** | Server Side Request Forgery | server fetches a user-supplied URL without validation/allow-list of host and scheme | V15 (egress); V2 |
| **API8:2023** | Security Misconfiguration | permissive CORS, missing security headers, verbose errors, unnecessary methods enabled | V13 Configuration; V4 |
| **API9:2023** | Improper Inventory Management | undocumented/legacy/`/v1` endpoints still live; debug or internal routes exposed; no API inventory | V13; V4 |
| **API10:2023** | Unsafe Consumption of APIs | trusting third-party API responses without validation; following their redirects; no timeout/size limits on consumed data | V15; V2 |

Cite the API item **and** the ASVS chapter together — e.g. a missing ownership
check is `API1:2023` + `ASVS V8` + `A01:2025 Broken Access Control`.
