# OWASP Top 10:2025 — risk classification

The 8th edition (first update since 2021). Use it as the **label** on a finding;
use ASVS (`asvs-5.md`) for the verifiable requirement behind it. Two categories
are new in 2025 (A03 Software Supply Chain Failures, A10 Mishandling of
Exceptional Conditions); A01 now explicitly covers API BOLA/BFLA authorization
and absorbed SSRF.

| Code | Title | Code-review cues | Maps to ASVS |
|---|---|---|---|
| **A01:2025** | Broken Access Control | object fetched by id with no ownership/role check (BOLA); function-level authz enforced only in the UI (BFLA); missing deny-by-default on new routes; SSRF via user-supplied URL | V8 Authorization (V2 for SSRF egress) |
| **A02:2025** | Security Misconfiguration | debug on in prod, default creds, permissive CORS, verbose errors, security headers absent, directory listing | V13 Configuration |
| **A03:2025** | Software Supply Chain Failures | unpinned/ranged deps, no lockfile, install-time scripts, non-registry sources, typosquats, unverified downloads | V15 Secure Coding and Architecture; dependency manifests |
| **A04:2025** | Cryptographic Failures | MD5/SHA1 for passwords, hard-coded keys/secrets, ECB mode, weak/again-used IVs, TLS off, plaintext PII | V11 Cryptography (V12 for transport) |
| **A05:2025** | Injection | string-built SQL, `child_process.exec` from input, unescaped HTML sink (XSS), template/LDAP/NoSQL injection, path traversal | V1 Encoding and Sanitization; V2 Validation |
| **A06:2025** | Insecure Design | missing threat model, no rate limit on sensitive flows, trust boundaries crossed without checks, business-logic abuse possible | V2 Validation and Business Logic |
| **A07:2025** | Authentication Failures | no lockout/rate limit on login, weak password policy, session fixation, credential stuffing possible, missing MFA on sensitive ops | V6 Authentication; V7 Session Management |
| **A08:2025** | Software or Data Integrity Failures | unsigned updates, insecure deserialization, CI/CD trusting unverified artifacts, integrity of critical data not checked | V2 (deserialization); V15 |
| **A09:2025** | Security Logging and Alerting Failures | security events unlogged, secrets logged, no alerting on auth failures, logs not tamper-resistant | V16 Security Logging and Error Handling |
| **A10:2025** | Mishandling of Exceptional Conditions | errors swallowed, fail-open on exception, sensitive info in error responses, inconsistent state after partial failure | V16 (V2 for fail-open logic) |

For each finding, name the A0x label **and** the ASVS chapter — the label tells
the reader the risk class, the ASVS reference tells them the property to fix.
